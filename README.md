# 🚀 Major League Hacking (MLH) Workspace

Welcome to the central repository for my Major League Hacking projects, workshops, and hackathon submissions. 

Major League Hacking empowers students through hackathons, developer programs, and global community events for the next generation of engineers. This repository documents my continuous learning and software engineering execution across various MLH events, including Global Hack Week. Global Hack Week is a recurring virtual festival where developers can learn new skills, complete technical challenges, and build a global portfolio.
